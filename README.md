# conquer123439.github.io

Personal homepage hosted with GitHub Pages.

- Live site: <https://conquer123439.github.io/>
- Source: `index.html` (single static page, no dependencies, no build step)

## How to preview locally

Option 1 — just open the file:

Double-click `index.html`, or open it in any browser.

Option 2 — serve it locally (optional):

```bash
cd github_homepage   # or the folder containing index.html
python -m http.server 8000
```

Then open <http://localhost:8000/> in your browser.
